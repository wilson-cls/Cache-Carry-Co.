# Cahce-Carry-Co.
Repository ini dibuat untuk memenuhi tugas besar mata kuliah **Pemrograman Web Dasar**. Website ini dirancang untuk memfasilitasi transaksi dan katalogisasi kendaraan-kendaraan fiksi dan unik, yang mencakup moda transportasi udara, laut, dan darat.

---

##  Catatan / Disclaimer
Website dan seluruh konten di dalamnya **murni bersifat fiktif, hiburan, dan simulasi belaka**. Seluruh transaksi, data kendaraan, dan fitur transaksi yang ada di dalam website ini hanyalah bercandaan/contoh kasus untuk keperluan tugas kuliah dan tidak mewakili transaksi di dunia nyata.
