# Tugas Besar Pemrograman Web Dasar  
**Developing Web Application (Kelompok)**

---

## Tujuan Project

Tugas Besar Pemrograman Web Dasar bertujuan melihat dan mengukur kemampuan mahasiswa dalam membangun sebuah aplikasi web. Aplikasi web yang dibangun bertujuan untuk menyelesaikan permasalahan dalam studi kasus.

---

## Ketentuan Project

1. Tugas Besar dilakukan secara **berkelompok**, setiap kelompok terdiri dari **5 – 6 mahasiswa**.
2. **Topik bebas** (mahasiswa dibebaskan dalam memilih topik).
3. **Topik tidak boleh sama** antar kelompok.
4. Penentuan topik kelompok paling lambat pada **Minggu, 8 November 2026**.

---

## Deskripsi Project

Mahasiswa diminta untuk membuat aplikasi web untuk menyelesaikan sebuah permasalahan dan harus memenuhi kriteria berikut:

- **Backend:** PHP murni (bukan framework)
- **Frontend:** XHTML, CSS, dan JavaScript
- **Fitur Utama:**
  1. Registrasi pengguna baru
  2. Enkripsi password yang dimasukkan pengguna ketika registrasi
  3. Login setelah registrasi
  4. Melihat dan mengupdate profil pengguna
  5. CRUD (transaksi) data ke sistem yang diproses melalui backend (**minimal 2 CRUD**)

---

## Bonus

1. **Admin UI:** Aplikasi web memiliki *User Interface* untuk menampilkan data yang diproses melalui *frontend* sebagai *user admin*
2. **Geolocation:** Aplikasi web menggunakan fitur *geolocation* jika relevan dengan topik yang dipilih
3. **Validasi Username/Email:** *Frontend* mampu mendeteksi jika username/email sudah dipakai pada saat melakukan registrasi
4. **Photo Profile:** Aplikasi web memiliki fitur untuk menambahkan atau mengupdate foto profil pengguna

---

## Delivery Project

- Delivery Project dilakukan pada **pertemuan ke-11 di tanggal 19 dan 20 November 2026**, serta **tanggal 28 November 2026** sebagai presensi pertemuan asinkron minggu 13.
- Setiap anggota kelompok **wajib hadir** dan perwakilan kelompok memaparkan progres project yang dikerjakan serta kendala yang dihadapi.

2. Pengumpulan dilakukan melalui situs kuliah oleh **seluruh anggota kelompok** sebagai pengganti presensi UAS berupa **link GitHub project** berisikan file *frontend* dan *backend*:
   - **Kelas A dan D:** 2 Desember 2026 pukul 23.59 WIB
