# Tujuan Project
Tugas Besar Pemrograman Web Dasar bertujuan melihat dan mengukur kemampuan mahasiswa 
dalam membangun sebuah aplikasi web. Aplikasi web yang dibangun bertujuan untuk menyelesaikan 
permasalahan dalam studi kasus

---

# Ketentuan Project
1. Tugas Besar dilakukan secara berkelompok, setiap kelompok terdiri dari 5 – 6 mahasiswa. 
2. Mahasiswa dibebaskan dalam memilih topik. 
3. Topik yang dipilih tidak boleh sama antar kelompok. 

---

# Deskripsi Project
Mahasiswa diminta untuk membuat aplikasi web untuk menyelesaikan sebuah permasalahan dan 
harus memenuhi kriteria sebagai berikut: 
1. Aplikasi web memiliki backend system berbasis PHP murni (bukan framework). 
2. Aplikasi web memiliki frontend system berbasis XHTML, CSS, dan JavaScript. 
3. Aplikasi web memiliki fitur untuk melakukan registrasi pengguna baru. 
4. Aplikasi web memiliki fitur enkripsi password yang dimasukkan pengguna ketika registrasi. 
5. Aplikasi web memiliki fitur login setelah registrasi. 
6. Aplikasi web memiliki fitur melihat dan mengupdate profil pengguna. 
7. Aplikasi web memiliki fitur untuk CRUD (transaksi) data ke system yang diproses melalui 
backend (minimal 2 CRUD) 

---

# Bonus
1. Aplikasi web memiliki User Interface untuk menampilkan data yang diproses melalui frontend 
sebagai user admin. 
2. Aplikasi web menggunakan fitur geolocation jika relevan dengan topik yang dipilih. 
3. Frontend mampu mendeteksi jika username/email sudah dipakai pada saat melakukan 
registrasi. 
4. Aplikasi web memiliki fitur untuk menambahkan atau mengupdate foto profil pengguna.

---

# Ketentuan Pengerjaan
1. Setelah topik kelompok dikumpulkan, kelompok akan diberikan notes progres yang harus 
dikerjakan dan akan digunakan sebagai bahan pemaparan progres pada delivery project 
pertama dan kedua. 
2. Pengumpulan dilakukan melalui situs kuliah oleh seluruh anggota kelompok sebagai pengganti 
presensi UAS. Pengumpulan berupa link GitHub project berisikan file frontend dan backend 
pada tanggal 2 Desember pukul 23.59 WIB untuk kelas A dan D, serta 3 Desember pukul 23.59 
WIB untuk kelas B dan C. 
Penamaan repository GitHub: TubesPWD_Kelas_Kelompok 
Contoh: TubesPWD_A_1 
3. Project akan dipresentasikan di kelas pada minggu ke-14 di tanggal 3 dan 4 Desember 2026. 
4. Project wajib merupakan karya asli/orisinal dari mahasiswa kelompok. 
5. Jika ditemukan kecurangan maka nilai mata kuliah Pemrograman Web Dasar akan langsung E.
